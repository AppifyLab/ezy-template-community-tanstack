# TanStack Start template

The EzyStudio Workspace starter: TanStack Start (React, SSR, server functions)
on Vite. Created for you by the platform — edit `src/routes/index.tsx` and the
Preview hot-reloads.

- Routes live in `src/routes/` (file-based, type-safe).
- `routeTree.gen.ts` is generated by the dev server — never edit it.
- Server-side fetches to the platform API: prefix with `EZY_SITE_URL`
  (see `src/routes/index.tsx`). Browser code can use plain relative URLs.
